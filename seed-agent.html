What Already Works

The prototype demonstrates a set of durable behaviors. Those behaviors are evidence for future designs—not code that every later implementation must inherit.

Continuity

Persistent Jobs

Long-running work carries an identity, history, plan, and completion path beyond one chat session.

Cognition

OPEVC Cycle

Work moves through Observe, Plan, Execute, Verify, and Condense instead of collapsing into one improvised action loop.

Context

Directory-Local Memory

Information stays close to the work that needs it, then condenses into durable knowledge after experience.

Safety

Plugins and Guards

Readable guidance and tested controls work together to protect the harness and keep recovery paths explicit.

Free evaluation access is available now for people studying the architecture, testing the prototype, or building alongside the series. Financial support is optional and never an access requirement.
