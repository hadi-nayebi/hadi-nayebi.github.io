Relationship map

Choose a path through the terms

Each path makes one relationship explicit. Terms may appear in more than one path because the same concept can connect capability, control, and growth.

Capability becomes action

Follow general capability into a bounded system that can do continuing work.

  1. ModelA model is a learned computational system that transforms supplied input into an inference, prediction, representation, or generated output.
  2. Large language model (LLM)An LLM is a model trained to predict or generate language tokens from context, often with additional training that supports instruction-following, tool selection, reasoning-like behavior, or structured output.
  3. RuntimeA runtime is the operational environment that connects a model to context, tools, processes, interfaces, and execution.
  4. HarnessA harness is the durable operational structure around model capability that makes continuing, bounded, inspectable work possible.
  5. AgentAn agent is model capability operating through a runtime and harness toward a bounded responsibility.

Control becomes agency

Trace how selected context and practical ownership expand a person's capacity.

  1. ContextContext is the selected information made available for interpreting and acting at a particular cognitive moment.
  2. HarnessA harness is the durable operational structure around model capability that makes continuing, bounded, inspectable work possible.
  3. User-ownedA harness layer is user-owned when the user has durable custody and practical authority to inspect, modify, copy, recover, move, and dispose of it without depending entirely on one provider's permission.
  4. AgencyAgency is the capacity to form purposes, make judgments, and cause directed change. In Hadosh Academy, externalized agency means part of a person's practical capacity is expressed through a harness they can understand and govern.

A seed becomes a system

See how a minimal starting substrate grows into durable, responsible operation.

  1. SeedA seed is the smallest coherent context or substrate from which a distinct harness can grow through use.
  2. ContextContext is the selected information made available for interpreting and acting at a particular cognitive moment.
  3. HarnessA harness is the durable operational structure around model capability that makes continuing, bounded, inspectable work possible.
  4. AgentAn agent is model capability operating through a runtime and harness toward a bounded responsibility.
Audit loop

Definitions mature in public

A definition becomes clearer by keeping its unresolved edges visible.

  1. DraftPublish the clearest current definition and its open questions.
  2. DiscussCollect critique, answers, counterexamples, and implementation evidence on that term's page.
  3. ReabsorbRevise the definition and close, replace, or sharpen the questions it can now answer.
  4. ConsolidateMark the term consolidated when its ambiguity is sufficiently resolved and Hadi accepts the wording.

Comments are evidence, not automatic authority. The visible definition changes only through reviewed repository history.
