Plugin

Current definition

A plugin is a bounded, composable, separately improvable harness module with one scoped responsibility. It may contribute instructions, context selection or injection, state, triggers or hooks, tool adapters, permission relationships, lifecycle rules, outputs, and verification, but no single file shape or mechanism is required. The runtime may load, invoke, or provide control points for a plugin; runtime, hook, and plugin are not synonyms. The harness retains the surrounding authority, routing, and source-of-truth boundaries, while the plugin owns only its declared scope. A dependable plugin makes its inputs, state, effects, failure behavior, and evidence inspectable enough to remove, replace, or adapt it without silently redefining the rest of the agent. Plugin portability therefore lives first in its responsibility and behavioral contract. Its concrete hooks, commands, files, APIs, and event wiring may remain runtime-specific.
