Agent

Current definition

An agent is model capability operating through a runtime and harness toward a bounded responsibility. The term names the acting system, not the model alone. An agent can interpret supplied state, make or propose decisions, use permitted tools, update owned state, communicate, and advance work under defined authority and verification. Its responsibility, permissions, and stopping conditions come from the user and harness. The same model can therefore animate many distinct agents because each harness supplies different context, tools, constraints, state, and accumulated experience. An agent should extend the user’s agency rather than silently becoming the owner of the user’s purposes.
