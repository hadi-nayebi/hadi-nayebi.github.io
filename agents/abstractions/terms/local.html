Local

Current definition

Local describes a harness layer operating within infrastructure the user directly controls, rather than existing only inside an external provider’s hidden application state. Locality can improve custody, inspectability, continuity, recovery, and the ability to replace providers. It does not automatically mean offline, private, secure, open-source, or completely self-hosted. A local harness may still call a remote model or service. Locality must therefore be described layer by layer: context can be local while inference is remote, and execution can be local while credentials or notifications depend on hosted systems. The practical question is what the user controls and what disappears when a dependency is removed.
