Frozen Reference

The private Claude Seed is no longer an access program.

The original private Seed is frozen as reference evidence and is not being developed toward a public release. The public work has moved to two new repositories built for different CLI architectures.

Current priority

Seed Agent — Codex

The primary public reimplementation. Codex remains the runtime while the Seed's cognitive/plugin and job layers are rebuilt from the lessons of the frozen reference.

Status: foundation only; not ready for general installation.
