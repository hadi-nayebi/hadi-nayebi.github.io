# Foundation Terms

**Source of truth:** [`data/abstraction-library.json`](../data/abstraction-library.json)  
**Public index:** [Canonical Abstraction Library](../agents/abstractions/)  
**Generated pages:** `agents/abstractions/terms/*.html`

The original aggregate draft has been separated into one auditable page per term. Each term carries one current definition, one state (`draft` or `consolidated`), and the unresolved questions that prevent consolidation.

Do not edit definitions in this roll-up. Update the structured source, run `node scripts/render-abstraction-library.mjs`, and review the resulting individual pages. Discussion attached to a term is evidence; accepted learning becomes canonical only when it is reabsorbed through a reviewed source change. Downstream harnesses consume the definition as the shared context block and translate it into their own runtime-specific mechanisms.
