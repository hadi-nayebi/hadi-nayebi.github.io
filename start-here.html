Start Here

Start with the CLI agent you already have.

POINT IT HERE. LEARN THE ARCHITECTURE. BUILD FROM IT.

If you already use Codex, Claude Code, OpenCode, Qwen Code, or another CLI agent, you already have enough to begin. Hadosh Academy can act as both a curriculum for you and a design reference for your agent.

Fastest path

Give your agent the website before you try to build the whole harness yourself.

Your CLI agent can read the same concepts you are learning. That means the Academy can teach both sides of the collaboration: you learn enough architecture to make decisions, and the agent gets enough context to help implement those decisions.

01

Open your CLI agent in a real project.

Use the runtime you already prefer: Codex, Claude Code, OpenCode, Qwen Code, or another capable local agent. The important thing is that it can work with your project files.

02

Point it at Hadosh Academy.

Start with this page, then let the agent follow the technical writing, project pages, and reference diagrams that match the question you are exploring.

03

Ask it to teach you in the language of your work.

The goal is architectural literacy, not memorizing implementation syntax. Ask the agent to translate jobs, plugins, phases, memory, guards, and authority into your profession.

04

Externalize one repeated behavior.

Choose something you already do repeatedly. Let the agent study the relevant design patterns, propose a small harness capability, and build it with you after you understand the objective and boundaries.

Starter instruction
Read https://hadi-nayebi.github.io/start-here.html and follow the relevant Hadosh Academy links from there. Teach me the core harness concepts in terms of the work in this project. Then identify one repeated behavior that would be useful to externalize into the harness. Explain the objective, state, interfaces, authority, and verification before proposing implementation. Do not change files until I understand and approve the plan.

The underlying architecture is the same vocabulary, but the useful behaviors are different. Choose the closest role and this section will translate the Academy into that kind of work.

Your work

A harness turns repeated judgment into durable working structure.

Start with the work you already understand. The agent does not need a generic “AI workflow”; it needs to learn what you repeatedly notice, remember, decide, verify, and carry from one job into the next.

        Enough language to steer
        Learn the anatomy, then let the agent handle more of the syntax.
        
            
        
                
        Job
        A durable unit of work with an objective, state, history, and completion path.
        “Take on a job to compare these three patent families.”
        
                
        Memory
        Context the harness preserves because future work may need it.
        “Remember that uncertainty must be reported separately from conclusions.”
        
                
        Plugin
        A bounded behavioral or operational capability with a clear objective and interface.
        “Add a behavior that checks every report for unsupported claims.”
        
                
        Phase
        A compartment for a kind of cognition such as observing, planning, executing, verifying, or consolidating.
        “Return to observation before changing the plan.”
