# papers/ — Whitepapers Working Memory
**Version:** v0.1.1

## Content Workflow

- **Source of truth:** `.pdf` files (committed to git)
- **Editing files:** `.md` files (gitignored, local-only)
- **Flow:** `.md` → `.pdf` (one-directional, md is draft)

### Naming Convention
- Slug format: `kebab-case-title`
- PDF: `papers/<slug>.pdf`
- Companion MD: `papers/<slug>.md` (gitignored)

### {Comment} Convention
- Same as blog: `{comments}` in `.md` files
- Agent scans via OBSERVE.comments

## New Paper Checklist

1. Place PDF in `papers/<slug>.pdf`
2. Create companion `papers/<slug>.md` (gitignored)
3. Add to `sitemap.xml`
4. Link from relevant blog post(s)
5. Update check-seo.sh counts
